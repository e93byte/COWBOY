# Screenshots

Upload the COWBOY screenshots to this folder. Suggested filenames:

- `sports-board.png` — sports board and schedule
- `game-details.png` — game details
- `free-picks.png` — free-pick experience
- `product-vision.png` — product concept artwork (vision only)

Supported formats include PNG, JPG, and WebP. Once uploaded, these files can be embedded in the repository README.
